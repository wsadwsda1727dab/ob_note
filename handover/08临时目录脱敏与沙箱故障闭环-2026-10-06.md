- 命令在 Windows PowerShell 中执行，执行目录为库根，无管理员权限要求。
- 本次改动的回退由 Git 承担，不另存副本。

```powershell

# 查看本次提交的改动

# 已推送时：追加反向提交，不改写远端历史
git @sd revert f0176dc

# 未推送且确认只回退本次提交时：撤回该提交，改动回到暂存区
git @sd reset --soft HEAD~1
```

- 何时应当回滚：脱敏改写导致故障线索无法复现（例如需要原样比对报错文本时），或「沙箱故障的处置」闭环被判定过早。
- 回滚会丢失什么：`reset --soft` 只动提交记录，不改内容；`revert` 会新增一笔提交，原提交仍在历史中。两者都会让第 9 章重新出现真实用户名，与 [[01交接文档写作格式]] 第 6.2 节冲突。

## 6. 回滚与恢复

- 命令在 Windows PowerShell 中执行，执行目录为库根，无管理员权限要求。
- `handover/` 文档的回退由 Git 承担，不另存副本。

```powershell
$repo = 'D:\User\Documents\Obsidian\ob_c1'
$sd = @('-c', "safe.directory=$repo", '-C', $repo)

# 查看本轮的两次提交及其逐文件统计（哈希以 git log 为准）
git @sd log --oneline -n 5
git @sd show --numstat --format="" HEAD

# 整体回滚第二次提交（未推送时可用；已推送则改用 revert）
git @sd revert HEAD

# 只回滚某一个文件到上一次提交
git @sd checkout -- 'handover/03ob_c1提交流程-2026-10-05.md'
```

- 何时应当回滚：发现某条闭环结论定错了、归档口径需要解除，或 `03` 第 8.3 节的规则移除导致扫描漏拦。
- 回滚会丢失什么：`revert` 只新增反向提交，原提交仍在历史里；`checkout --` 会丢弃该文件当前未提交的改动；回滚删除线改动后，`00总览` 的第 100 行「已闭环」说明也需要一并回退，否则两处口径不一致。
- 回滚不会影响：`04` 第 2 章已刷新的指纹反映的是当时的真实文件状态；只有当文件再次被改写时才需重新刷新。
- 全局指令文件不在 Git 管辖内，回退需手工删掉 `%USERPROFILE%\.dsh\AGENTS.md` 中那一行；写入前的原文可从 `02` 第 2 章登记的版本指纹与 `diff` 核对。

## 8. 复现方法

### 8.1 提交前敏感值扫描

- 只读操作，不修改任何文件；在库根执行，判据是「只拦新增暴露」：逐值比对工作区与 `HEAD`，出现任何新值一律中止，不执行 `git add`。
- 规则集见 [[03ob_c1提交流程-2026-10-05]] 第 8.3 节；报告只输出文件、规则与命中次数，不回显内容。

```powershell
$repo = 'D:\User\Documents\Obsidian\ob_c1'
$sd = @('-c', "safe.directory=$repo", '-c', 'core.quotepath=false', '-C', $repo)
$rules = @(
  @{n='gh-token';p='gh[pousr]_[A-Za-z0-9]{30,}'},
  @{n='sk-key';p='sk-[A-Za-z0-9]{20,}'},
  @{n='aws-key';p='AKIA[0-9A-Z]{16}'},
  @{n='private-key';p='-----BEGIN [A-Z ]*PRIVATE KEY-----'},
  @{n='kv-cred';p='(?i)(password|passwd|secret|api[_-]?key|token)\s*[:=]\s*\S{6,}'},
  @{n='intranet-ip';p='\b(?:10\.\d{1,3}|192\.168\.\d{1,3}|172\.(?:1[6-9]|2\d|3[01])\.\d{1,3})\.\d{1,3}\b'},
  @{n='hostname';p=[regex]::Escape($env:COMPUTERNAME)},
  @{n='username';p=[regex]::Escape($env:USERNAME)},
  @{n='email';p='[\w.+-]+@[\w-]+\.[\w.-]+'}
)
$paths = git @sd status --porcelain=v1 --untracked-files=all |
  ForEach-Object { if ($_.Length -gt 3) { $_.Substring(3).Trim('"') } }
$totalNew = 0
foreach ($f in $paths) {
  $full = Join-Path $repo $f
  $work = if (Test-Path -LiteralPath $full) { [System.IO.File]::ReadAllText($full) } else { '' }
  $head = (git @sd show ("HEAD:" + $f) 2>$null) -join "`n"
  foreach ($r in $rules) {
    $wset = [System.Collections.Generic.HashSet[string]]::new()
    foreach ($m in [regex]::Matches($work, $r.p)) { [void]$wset.Add($m.Value) }
    $hset = [System.Collections.Generic.HashSet[string]]::new()
    foreach ($m in [regex]::Matches($head, $r.p)) { [void]$hset.Add($m.Value) }
    $new = @($wset | Where-Object { -not $hset.Contains($_) })
    if ($new.Count -gt 0) { Write-Output ("HIT-NEW {0} | {1} | {2}" -f $f, $r.n, $new.Count); $totalNew += $new.Count }
  }
}
Write-Output ("TOTAL-NEW-EXPOSURES: {0}" -f $totalNew)
```

- 预期输出：末行为 `TOTAL-NEW-EXPOSURES: 0`，且不出现任何 `HIT-NEW` 行；出现即中止提交。

### 8.2 文档指纹核对

- 用于验证本篇第 2 章与 `04`、`05` 第 2 章声明的字节数、行数与 `SHA-256` 是否与实际文件一致；改这些章节约定的文件后必跑一次。

```powershell
$files = @(
  'handover/00总览-2026-10-05.md',
  'handover/01交接文档写作格式-2026-10-05.md',
  'handover/02DSH全局指令安全边界-2026-10-05.md',
  'handover/03ob_c1提交流程-2026-10-05.md',
  'handover/04handover总览与库根README-2026-10-05.md'
)
foreach ($f in $files) {
  $b = [System.IO.File]::ReadAllBytes($f)
  $hex = (([System.Security.Cryptography.SHA256]::Create().ComputeHash($b)) |
    ForEach-Object { $_.ToString('X2') }) -join ''
  $lines = (Get-Content -LiteralPath $f -Encoding UTF8).Count
  Write-Output ("{0}|{1}|{2}|{3}" -f $f, $b.Length, $lines, $hex)
}
```

- 预期输出：5 行 `路径|字节|行数|SHA-256`，与第 2 章声明的值逐一相符；不一致说明有文件被改写而台账未刷新。

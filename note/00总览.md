# 一、笔记库总览

## 1 基本信息

- **库名称**：ob_c1
- **用途**：记录 Git/GitHub、Obsidian 同步、Skills 与 DSH 插件安装、Python 环境等工具操作与规范
- **笔记位置**：全部正文放在 `note/` 目录，根目录只保留 Obsidian 配置与 Git 配置文件
- **命名约定**：`NN名称.md`，`NN` 为两位序号，名称用下划线连接，新增笔记顺延编号
- **本页定位**：既是全库导航，也说明各篇范围与阅读顺序

## 2 同步与排除说明

- `.obsidian` 目录整体跟踪，便于多设备保持一致配置
- `.obsidian/workspace.json` 与 `.obsidian/graph.json` 只记录本地界面状态，已排除跟踪
- 排除原因与操作细节见 [[03Git_obsidian]]

## 3 阅读提示

Git 主线由三篇组成：[[01Git_command]] 是速查表，[[02Gituse]] 是原理与场景详解，[[03Git_obsidian]] 是落到本库的实际做法。

**01 与 02 内容有重叠**（如 `checkout`/`switch`/`restore`/`reset` 的分工、取消暂存、恢复文件、取消跟踪）。两者定位不同：

- 只查命令写法：看 [[01Git_command]]
- 要理解为什么、走完整流程：看 [[02Gituse]]
- **重叠部分如出现不一致，一律以 [[02Gituse]] 为准**

三篇已按下述分工消重，遇到同一命令时按这个顺序找：

- [[01Git_command]] 只保留命令速查表（含旧版 `master`、`main` 两种写法）
- [[02Gituse]] 只保留原理、场景与完整流程，不再重复命令清单
- [[03Git_obsidian]] 只保留本库专属内容（`.gitignore` / `.gitattributes` 实际规则、排除原因、插件设置），通用流程改为双链指向前两篇
